UniverseLab Guide

A compact scientific guide to the architecture, modules, equations, result interpretation and evidence limits of UniverseLab. German remains the canonical research language.

Architecture

HPVS → HZT-M0 → HZT-Full

HPVS is the audit and validation layer. HZT-M0 is the minimal model layer used to establish controlled, auditable reference structures. HZT-Full is reserved for extensions that pass the required consistency and evidence gates.

How to read a status

  • PASS / established: the stated gate is satisfied within its declared scope.
  • CONDITIONAL: result depends on explicit assumptions or missing closure work.
  • OPEN: not decided.
  • BLOCKED / rejected: the tested mechanism fails its stated gate.
  • NOT RELEASED: downstream inference is not authorized.

Low-energy control

E, H, k/a ≪ mχ, mKK

This hierarchy is a decoupling condition for a GR-like four-dimensional regime. It is not evidence that nature realizes the underlying six-dimensional model.

Observable chain

6D parent parameters → 4D EFT → observables → instrument/selection model → likelihood

Observational comparison becomes admissible only when every required map is released and provenance-controlled.

Core interpretation rules

Numerical stability does not establish ghost freedom. Technical feasibility does not establish physical identification. A good fit does not confirm a theory. A fitted parameter is not a derivation from the six-dimensional parent sector.
